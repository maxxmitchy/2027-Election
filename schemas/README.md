# Schemas

These JSON Schemas define the initial machine-readable contract for the repository. They are database-agnostic and can later be implemented in PostgreSQL or another suitable store.

Core schemas:

- `candidate.schema.json`
- `claim.schema.json`
- `source.schema.json`
- `evidence.schema.json`
- `economic-observation.schema.json`
- `review.schema.json`
- `version.schema.json`

Future schemas should cover administrations, parties, offices, events, metrics, analyses, calculations, datasets, answers and source archives.
