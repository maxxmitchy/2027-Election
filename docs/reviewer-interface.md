# Reviewer Interface Foundation

Review is metadata about evidence quality; it is not evidence itself.

The product reserves a review surface for:

- Evidence quality
- Factual accuracy
- Calculation accuracy
- Context completeness
- Source quality
- Reviewer confidence

A review can assess a claim/evidence/calculation chain without changing the underlying evidence record. Historical evidence is immutable from the public product surface. Corrections create new versions and preserve prior state.

Popularity, reactions and public voting are intentionally separate from review status.
