# Phase 6 — Evidence Acquisition & Research Execution

## Public milestone language

**IMPLEMENTED:** Evidence acquisition, capture, verification, retrieval-event, source-version and evidence-extraction primitives are implemented as a distinct layer after the Phase 5 Research Workbench.

**EXECUTED:** The controlled Phase 6 CI workflow executes representative acquisition tasks against a deliberately small public-source corpus and preserves exact execution identity and evidence artifacts.

**VALIDATED:** Validation requires Phase 3, Phase 4 and Phase 5 regressions, Phase 6 tests, acquisition execution, JSON Schema validation, candidate isolation and mutation testing to pass in the same exact CI execution.

**PASS:** This milestone must not be described as PASS until the actual Phase 6 CI run has passed all fail-closed gates.

The governing boundary remains:

> Discovery is not verification.
> Source is not evidence.
> Evidence is not review.
> Statement is not truth.
> Retrieval failure is not falsity.
> Missing evidence is not negative evidence.
> Temporal association is not causation.
