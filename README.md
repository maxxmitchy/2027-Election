# 2027 Election

An evidence-based, version-controlled research archive on Nigeria's 2027 presidential election.

The project will document presidential candidates, political records, public statements, governance outcomes, economic indicators, historical events, controversies, source evidence, corrections, and competing claims.

The objective is to build a clean, auditable information layer that can eventually support direct AI retrieval with evidence, provenance, confidence levels, calculations, reviews, and historical versions.

Core principles:
- Evidence before assertion.
- Primary sources before secondary sources where available.
- Facts, allegations, analysis, and opinions must be clearly distinguished.
- Important claims should be corroborated where practical.
- Corrections must be recorded rather than silently erasing history.
- Historical versions must remain traceable.
- Community reviews supplement evidence but do not replace primary evidence.
- Uncertainty must be represented honestly.
